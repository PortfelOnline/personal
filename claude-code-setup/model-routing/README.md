# Model routing — экономия токенов Claude Code (2026-07-16)

Дёшево вниз, дорого решает. Механику отдаём дешёвым субагентам, opus-тред бережём
(у субагента своя изолированная сессия/кеш — главный prompt-кеш ~97% hit не сбрасывается).

## Лестница агентов (`~/.claude/agents/`, копии здесь)

| Уровень | Агент | Модель | Задачи |
|---|---|---|---|
| дёшево | `explore-lite` | haiku | поиск символов/кода, скан логов, листинги, извлечение значений (read-only) |
| дёшево | `chore-lite` | haiku | механические переименования, формат, бойлерплейт по чёткому спеку |
| средне | `impl-lite` | sonnet | тесты к готовому коду, ревью дифа, однофайловая правка по спеку, доки из плана |
| дорого | главный тред / `code-review-expert`, `refactoring-expert`, `db-migration-agent` | opus | архитектура, мультифайл-рефактор, дебаг с неизвестной причиной, **всё что влияет на поведение продукта** |

## 🚨 Break-even gate (когда делегировать)

Хэндофф ≈ 300–800+ токенов оверхеда. Делегировать только если:
- механика **> ~1.5k токенов** И координация **< 30%** ожидаемой экономии;
- задача **< ~100 токенов описания** → делать inline;
- **макс 2 субагента** на связную задачу;
- результат субагента **lossy** (сворачивается в главный контекст).

## 🚨 Почему НЕ через ds-proxy

Свитч модели в середине сессии сбрасывает prompt-кеш (~97% hit) → дороже, не дешевле.
Прокси-роутеры (NadirClaw и пр.) для Claude Code бесполезны: агентный цикл всегда с tools →
классификатор форсит complex-модель, а кеш Anthropic они не адресуют.

Экономия — только через субагентов (или per-session `/model haiku`/`sonnet` для заведомо простых сессий).
